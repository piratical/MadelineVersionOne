FIXED Results Interpretation


A FIXED analysis both estimates distance between markers and gives local support for a given order by running a FLIPS calculation with 2 markers per tuple. Columns 2-4 (or 2-7 for sex-specific calculations) give theta (the recombination fraction) and the estimated map distance in centiMorgans using whichever mapping function you specified. For each marker, the cumulative distance is also given. The last two columns give the LOD score and the odds (10 raised to the lod score) of the given order versus the reverse rder for each successive pair of markers.
