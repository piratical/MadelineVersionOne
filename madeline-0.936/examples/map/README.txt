Madeline README.txt for examples/map directory
2003.01.23.ET
================================================================

The files:

   map_o_mat_chr1_sex_specific.html  and
   map_o_mat_chr1_sex_averaged.html

... respectively contain a sex-specific and sex-averaged map
of eight SNP markers on chromosome 1 generated by
the Rutger's Map-O-Mat online Crimap-based genetic
map server at http://compgen.rutgers.edu/mapomat.

The file:

   chr1.map
   
... contains the same data in a Madeline flat-file format.
Note how the recombination fractions and distances are stored
in the row containing the name of the FIRST marker, and thus the
last row of the map contains missing values for these columns.

Running the command:

   M> recognize 'chr1.map'
   
... will cause Madeline to create the Madeline binary header
file called:

   chr1.map.mfh
  
... and you can then use the "load" command to load the map:

   M> load 'chr1.map.mfh'

To verify that the map has been correctly loaded, use the
"list map" command:

   M> list map

... or, if the map table contains maps for multiple chromosomes:

   M> list map for chromosome=1
